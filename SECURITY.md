# Seguridad

Este repositorio contiene documentación y un sitio estático; no distribuye
binarios de gentle-ai.

## Vulnerabilidades de gentle-ai

Reporte vulnerabilidades del producto mediante los canales definidos por el
repositorio upstream: <https://github.com/Gentleman-Programming/gentle-ai/security>.
No publique aquí detalles explotables antes de coordinar con upstream.

## Vulnerabilidades de este sitio

Para problemas del HTML/CSS/JavaScript o exposición accidental de datos, abra
un reporte privado de seguridad en:
<https://github.com/JNZader/gentle-ai-review/security/advisories/new>.

No incluya credenciales, tokens, cookies ni información personal sensible.
